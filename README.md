## 📌 Overview

Star Wild Healthcare Agency is a responsive web platform developed using HTML, CSS, and JavaScript to support wildlife healthcare, conservation awareness, and safari management.

This project combines public services (safari booking, donations, injury reporting) with internal tools (medicine & equipment management) to create a centralized digital system for wildlife protection.
